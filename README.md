# AutoChannelSidebar

Automatically resizes the channel sidebar to fit the longest channel name in the server you're viewing.

The width updates when you switch servers or the channel list changes. Since the sidebar is sized automatically, its resize handle is disabled while the plugin is active.

## Settings

The **Minimum Sidebar Width** setting lets you choose a minimum width from 264 to 600 pixels.

## Installation

This is a Vencord userplugin and requires a Vencord build from source. Download the latest [release](https://github.com/JumbleBumble/AutoChannelSidebar/releases), extract the ZIP file, place the `AutoChannelSidebar` folder in `src/userplugins`, build Vencord, enable AutoChannelSidebar in the Plugins settings, and restart Discord. See Vencord’s [custom plugin instructions](https://docs.vencord.dev/installing/custom-plugins/) for details.

If you're setting up a Vencord build with custom plugins, I recommend using [Vencord Custom Updater](https://github.com/JumbleBumble/Vencord-Custom-Updater) to keep your Vencord install current while preserving custom plugins like AutoChannelSidebar.
