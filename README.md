# AutoChannelSidebar

Automatically resizes the channel sidebar to fit the longest channel name in the server you're viewing.

The width updates when you switch servers or the channel list changes. Since the sidebar is sized automatically, its resize handle is disabled while the plugin is active.

## Settings

The **Minimum Sidebar Width** setting lets you choose a minimum width from 264 to 600 pixels.

## Installation

This is a Vencord userplugin and needs a Vencord build from source. Put this folder in `src/userplugins/autoChannelSidebar`, then rebuild Vencord and restart Discord. See Vencord's [custom plugin instructions](https://docs.vencord.dev/installing/custom-plugins/) for details.
